Infix to Postfix Conversion and Expression Trees

The operands are written in the same order as the infix expression. Operators are
placed after their operands according to precedence and associativity.

 a. (A + (B - C) * D)
    Postfix: ABC-D*+

    Expression tree:
          +
         / \
        A   *
           / \
          -   D
         / \
        B   C

 b. (A + B) * (C - D)
    Postfix: AB+CD-*

    Expression tree:
          *
         / \
        +   -
       / \ / \
      A  B C  D

 c. (A + B) * (C - D) / E
    Postfix: AB+CD-*E/

    Expression tree:
            /
           / \
          *   E
         / \
        +   -
       / \ / \
      A  B C  D

 d. (A + (B * C - (D / E ^ F)))
    Postfix: ABC*DEF^/-+

    Expression tree:
            +
           / \
          A   -
             / \
            *   /
           / \ / \
          B  C D  ^
                  / \
                 E   F

 e. 12 / 3 * 6 + 6 - 6 + 8 / 2
    Postfix: 12 3 / 6 * 6 + 6 - 6 + 8 2 / +

    Expression tree:
              +
             / \
            -   /
           / \ / \
          +  6 8  2
         / \
        *   6
       / \
      12  3
